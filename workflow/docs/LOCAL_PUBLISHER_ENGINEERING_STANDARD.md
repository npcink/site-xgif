# XGIF 内容工具工程规范

状态：当前有效；最后更新：2026-11-12。旧发布台界面与 API 规范由 [ADR-019](../../site/docs/decisions/ADR-019-ai-managed-static-content.md) 取代。

## 范围

`workflow/` 只保留 AI 可按需调用的命令行工具和共享规则；不得恢复管理界面、常驻 HTTP 服务、内置 AI 编辑器或第二份正文数据库。AI 在内容文件上工作，工具负责可验证的检查、版本、资源与恢复。

## 数据边界

Markdown 是正文和元数据依据，`contentId` 不可重建。R2 或公开资源目录保存图片字节。SQLite 和感知缓存是可重建派生数据，仅按需使用。私有正文、图片字节备份、回收站、`.env`、SQLite 和发布回执保留本机私有；不部署、不放入公开 Git。

## 文件与发布

- 先读取再修改，精确检查差异，保留其他任务的变更；改写或删除前及批次结束后创建私有快照。
- 内容检查、来源和授权、完整性确认、内部复核、稳定 ID 与已有 hold 均不因换成 AI 操作而放宽。
- 自动整理段落只允许增加空行，不改写原文；短文不靠扩写通过门槛。
- 命令默认检查，外部写入需显式参数；新同步/上传入口共用独占工具锁，旧维护脚本和外部文件操作也应顺序执行。
- 发布只复制选中公开 Markdown 及引用图片，从最新 `origin/main` 隔离建分支并校验文件哈希，不能夹带开发提交或私有数据。
- 推送前保留 prepared 回执，终态持久化后才清理分支；失败沿用原批次恢复，不发布当前开发分支。
- 创建 PR 不自动合并；远端失败保留已推送事实、原分支和下一步。PR、构建与真实线上版本分别核验。
- 图片以 SHA-256 内容寻址，原始字节先私有备份；感知查重仅提供人工候选，不自动删除。图片授权不能由 AI 推测。
- 下架使用版本化文件删除并核对线上消失，不删除 R2 字节来代替内容下架。R2 清理维持 30 天观察、单对象完整键、远端和私有备份检查。

## 验证

工具变更运行 `cd workflow && npm test`；涉及站点内容和契约时同时运行 `cd site && npm test`，再 `git diff --check`。外部写入的新入口应覆盖默认检查无外部写入、非法或草稿内容被拒绝、哈希变化与失败恢复。测试使用隔离目录，不操作真实 R2 或生产内容。

合并前按正确性、可维护性、边界、安全和回归风险审查。架构变更写 ADR，README 保持当前操作方式。旧阶段文档作为历史保留，不继续维护已删除界面的交互契约。
