# 上传后由 M4 整理图集

日期：2026-11-03

日常流程：添加 1–12 张图片 → 全部上传成功后自动整理 → 保存并预览 → 保存前确认 → 本地已保存。图片编辑页只提供本地保存与“查看效果”，不提供上线动作。多份内容可分别保存，之后进入“同步上线”工作区点击“批量上线 N 条”；也可在内容库批量模式使用“批量上线所选”。批量提交继续走原有内容分支、PR、部署及线上核验流程，不自动合并 PR；保存草稿不进入待上线队列。

同一图片再次编辑保存会更新原文件，使用最新内容版本参与批量上线，不重复新建。未保存修改只在浏览器临时暂存，不会参与上线。

本地保存成功后，顶部显示“本地已保存”和“查看效果”链接，在新标签页打开已保存图片的本地站点页面。重新打开该内容时也保留入口；草稿、非公开图片或存在未保存修改时不显示该链接。

图片预览上方显示处理进度，按上传、逐张识别、整理资料、人工确认四阶段标明当前位置，显示实际完成张数及当前模型；识别单张图片期间不虚构百分比或剩余时间。

## 桌面编辑布局

- 编辑画布只显示当前图片，按可用屏幕高度完整缩放，不裁切；点击图片打开原图查看窗口，支持关闭按钮与 Escape 返回。
- 最多 12 张图片在横向缩略图带中排列。选中一张后，下方只编辑它的描述、顺序、封面和移除操作；切换图片不保存或上线内容，逐图描述仍绑定原图片。
- 处理进度保留当前阶段、实际张数和异常提示，模型、版本及更新时间收进“识别详情”。完成后收起进度条和阶段列表，重新识别与重试入口继续保留。
- 右侧资料面板按内容高度结束，滚动时保持在保存工具栏下方；长内容只在面板内滚动。标题、描述、标签直接显示，分类、情绪与场景在“分类与使用场景”内。
- 相似图检查正常时显示一行结果与可展开的检查说明；候选、检查不完整或失败时保留详细提示。保存前的质量与人工确认流程不变。

## 更换模型与重新识别

- 点击“重新识别”会以当前配置创建独立任务，跳过旧识别缓存，保留原任务和结果。新建议逐项显示当前值与候选值，默认均不勾选；只有点击“采用所选建议”才更新选中的共享资料或逐图描述，之后仍需检查、保存前确认。
- 自动首次整理继续保护手工修改；重新识别及换模型后的整理采用对照模式，来源、作者、授权、日期及发布状态不会由 AI 改写。重新识别任务与对照模式会随浏览器临时暂存恢复。
- 将 `workflow/.env` 的 `XGIF_IMAGE_AI_MODEL` 改为 M4 上已安装且可用的模型，执行 `npm --prefix workflow run restart`，刷新页面后点击“重新识别”。本功能不会安装、下载或自动切换模型。
- 如模型名称不变但权重更新，设置新的 `XGIF_IMAGE_AI_VERSION` 标签后重启。缓存同时区分模型名称、权重版本、端点、提示词版本与图片字节指纹，避免把旧结果当成新模型结果。私有任务记录模型、版本、提示词版本与创建/更新时间，不写进公开 Markdown。

## 自动处理与人工确认

- 发布台按图片 SHA-256 逐张识别，再用逐图结果汇总标题、描述、规范标签、分类、情绪和场景；替代文本独立保存在每张图片中。
- 上传顺序保持不变。AI 可以建议封面，只有点击“采用 AI 建议封面”才改变首张。
- 每张图片显示上传与 AI 状态。识别疑问、失败和主题混杂提示集中在工作台及保存预览中；失败图片可单独重试，已完成的图片不会重复识别。
- 来源类型沿用人工选择，浏览器记住常用类型。AI 输出不接受来源、作者、链接和授权字段。未知来源如实披露；新“用户提供素材”或追加素材须人工填写有效确认日期，不能由当天日期自动补齐授权。
- 保存预览展示全部图片、逐图描述、共享资料、来源声明和相似图片对照，可点击查看原图。有待检查项目时，需勾选确认才能保存；也可返回修改。
- 本机发布台统一使用 `no-referrer`，让确认预览、恢复后的缩略图和相似图加载时不携带本机地址，兼容图床现有防盗链规则。R2 对象存在、无来源请求成功不能替代浏览器实际显示验证。
- 预览回执绑定图片顺序、替代文本、公开资料、编辑版本和 AI 结果版本。资料、图片或 AI 结果改变后必须重新预览。保存时再次检查资源和重复内容。

## M4 配置与连接

图集使用独立配置，仅允许本机回环地址（包括 SSH 隧道），不回退到文章 AI 配置。密钥与地址保留在被 Git 忽略的 `workflow/.env` 中。

```dotenv
XGIF_IMAGE_AI_BASE_URL="http://127.0.0.1:11436/v1"
XGIF_IMAGE_AI_MODEL="npcink-vision:qwen35-4b-instruct-16k-v1"
XGIF_IMAGE_AI_VERSION=""
XGIF_IMAGE_AI_TIMEOUT_MS="120000"
XGIF_IMAGE_AI_SSH_HOST="user@m4-host"
```

`XGIF_IMAGE_AI_SSH_HOST` 可省略以复用已有本地服务或自行建立的隧道。填写时，发布台在首次请求或重试前检查连接，按需建立到 M4 回环端口 11434 的 SSH 转发；需要现有 SSH 密钥、可达的 M4 和已连接的网络。只管理自己创建的 SSH 子进程，发布台退出时关闭它，不修改 M4 服务监听或安装模型。已有健康端点可直接复用。网络恢复后点击“继续整理 / 重试”即可重连。

M4 实机为 16GB Mac mini，已有上述 4B 视觉模型。兼容接口需设置 `reasoning_effort: none`，避免思考输出耗尽结果长度。默认一次仅执行一个识图或汇总请求，每次超时上限 120 秒。

## 恢复与边界

- 任务及结果保存在 SQLite 所在目录的 `gallery-ai/jobs/`（默认 `workflow/.runtime/gallery-ai/jobs/`），发布预览回执保存在相邻的 `reviews/`。均为本地私有资料，不进入公开内容、Git 或静态构建。
- 写入使用临时文件加原子替换。服务重启后保留已完成项目，未完成任务标为暂停；重新打开上传草稿或点击继续会恢复。新增、移除或排序产生新的整套汇总，成功的逐图识别按字节指纹、模型、端点和提示版本复用。
- 单图解码或结果格式失败不影响其余图片；M4 连接中断或超时会暂停剩余任务，避免为 12 张分别等待超时。
- 浏览器暂存图片引用、编辑资料和手动修改保护状态。尚未上传成功的文件暂存在 IndexedDB，刷新后按原顺序恢复并续传，已成功图片无需重传。上传完成后以小体积引用原子替换暂存字节，即使关闭页面发生在草稿更新前也能恢复。浏览器空间不足、禁用存储或清除网站数据时不能保证恢复，界面会明确提示在关闭前完成上传或重新添加。
- 用户编辑过的共享字段、逐图描述（包括主动清空）不会被后续 AI 结果覆盖。生成期间切换编辑对象或图集成员，会丢弃旧页面上下文的异步结果。
- GIF / 动态 WebP 抽取首、中、尾最多 3 帧，并强制提示检查完整动作含义；不是完整视频理解。相似图检查仍只比较首帧。
- 返回的 JSON、字段类型、长度及规范标签经过校验。AI 识别准确性仍需人工复核；不能凭模型自报确定性推断正确。
- 确认回执记录预定内容 ID 和预期 Markdown 哈希，重复请求复用已保存结果。若 Markdown 已写入但回执终态未写入，重试可核验文件并恢复，不新建第二条内容。

## 接口

| 接口 | 契约 |
| --- | --- |
| `GET /api/ai/gallery-status` | 返回已配置状态、`model`、可选权重标签 `modelVersion` 和回环地址，不表示实时模型健康 |
| `POST /api/ai/gallery-jobs` | `{images,force?:boolean}`，只接收已上传的本地图片或有台账与字节备份的 R2 图片；`force:true` 创建独立任务且跳过识别缓存。返回 `202 {job}`；新增任务字段含 `modelVersion`、`fresh`、`createdAt`，旧记录缺少这些字段时继续兼容 |
| `GET /api/ai/gallery-jobs/:id` | 返回逐图状态、结果、错误、整套汇总和版本 |
| `POST /api/ai/gallery-jobs/:id/retry` | 可选 `{hashes}`，只重试相应失败项，成功项保留 |
| `POST /api/image-reviews` | `{data,file?,expectedContentSha256?}`，返回质量结果及私有预览凭据 |
| 现有发布 / 更新接口 | 携带 `galleryReviewId` 与必要的 `galleryWarningsConfirmed`；AI 图集正式发布必须经过预览 |

已有手动接口继续兼容；界面统一通过预览提交。旧单图、旧外链可继续手动编辑；没有可核验字节的旧外链不由服务端下载识图。

## 验证

单元与故障注入覆盖：12 张、单项失败、指纹重用、任务中断、全局断线暂停、GIF 抽帧、结果格式错误、来源字段丢弃、回环限制、SSH 重连、预览版本绑定及重复保存。

真实 HTTP 流程覆盖：上传→后台识图→预览→确认→保存，资料变化拒绝、确认缺失拒绝、重复请求及写入后中断恢复。浏览器覆盖自动触发、处理中手动编辑保护、逐图重试、刷新恢复、失败文件自动续传与原始顺序、上传完成与草稿更新之间中断、浏览器存储不可用、图集变化、封面选择和相似图集中确认。

M4 样例实测：单张图片及整套汇总约 23 秒；12 张（1 张复用前次识别）约 88 秒，全部完成且识别出混合主题。另用两张自制中文图片跑通真实页面自动填写，并人工检查工作台与集中确认界面。耗时仅代表这些样例及当时负载。

最终本机验收：发布台 205 项单元测试、真实 HTTP 集成与 29 项浏览器测试通过；站点 47 项检查、构建和 162 页链接检查通过。已在 1280 × 800 人工检查编辑器和集中确认窗口，确认按钮固定在可见底部。GIF 抽帧识别、M4 隧道建立及断开后重连已实机验证。没有进行真实 R2 写入或合并部署。
