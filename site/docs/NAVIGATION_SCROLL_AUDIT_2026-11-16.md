# 导航与滚动专项复盘

日期：2026-11-16。本文记录本次检查范围与方法，不代表此后版本或所有浏览器已无问题。

## 原定目标

独立详情页的推荐正常跳页；列表内可以连续浏览同一个弹窗；前进、后退、关闭和刷新后，地址、内容和展示方式保持一致。长说明及图集只有一个纵向滚动容器，来源和操作可到达。

## 完成情况

- PR #89 已修复独立页推荐被拦截、刷新后的旧历史误开弹窗，以及图片说明栏的第二条纵向滚动条。
- 扩大检查发现并修复：弹窗前进／后退虽恢复正确内容，却丢失阅读位置和图集当前图片。
- 本次保持原文、原图、内容元数据和推荐清单不变，不新增服务或依赖。

## 发现的问题

| 严重程度 | 具体问题 | 根本原因 | 改进 |
| --- | --- | --- | --- |
| 必须改正 | `discovery.behavior.spec.mjs` 原用例在独立文章页点击推荐后断言弹窗已加载 | 测试照着现有实现编写，未先区分独立页面与列表弹窗的用户预期；绿测试固化了错误行为 | 独立页断言主内容 ID 和弹窗关闭；列表断言同一个弹窗及正确内容 |
| 必须改正 | `site.visual.spec.mjs` 的图片弹窗基线选取短说明，未暴露长说明栏的嵌套滚动 | 把一个首屏截图代表性样本当作整个布局的验收，没有检查内容极值与内部滚动容器 | 长说明及真实图集在 390、768、1280 宽度核对纵向滚动容器和来源可达性 |
| 必须改正 | 旧弹窗历史测试只确认 `aria-busy=false`，未核对内容 ID、阅读位置或图集选中项 | 验收止于“能打开”，没有检查完整返回路径恢复了哪些状态 | 返回／前进断言内容 ID、独立历史条目的滚动位置及选中图片对应的原图链接 |
| 应当改正 | 未覆盖弹窗刷新、请求未完成时关闭及获取失败后的独立页回退 | 只检查顺畅的主要路径，遗漏浏览器生命周期与异步边界 | 保留刷新后历史、加载中 Escape、失败回退和关闭后页面解锁的浏览器回归 |
| 应当改正 | `csp.behavior.spec.mjs` 在测试完成后仍处理虚拟主机请求，偶发 `Fetch response has been disposed` | 测试的异步资源未在上下文销毁前收口，重试通过不能证明测试稳定 | 断言完成后移除路由，仅忽略收尾期间被取消的路由处理；保留测试执行期间的失败与全部 CSP 断言 |

这些属于实现与验收责任，不能归因于用户没有提供足够样本。测试通过只能证明已写出的断言通过，不能代替用户行为是否合理的判断。

## 检查结果与边界

| 路径／场景 | 检查内容 |
| --- | --- |
| 首页、文章分页、动图筛选、搜索、标签 | 打开详情、Escape、前进、关闭；恢复原 URL、筛选结果、页码、页面位置及键盘焦点 |
| 收藏 | 打开独立页、返回收藏列表；测试拦截汇总接口，避免写入模拟收藏统计 |
| 独立文章、独立图片 | 推荐正常跳页，返回主内容正确且弹窗关闭 |
| 弹窗图文连续浏览 | 复用单个弹窗，前进／后退对应正确内容，关闭回原列表 |
| 长说明与真实图集 | 手机、平板、桌面宽度下只允许外壳纵向滚动；不横向溢出；来源可到达 |
| 弹窗历史 | 返回／前进恢复各条目的阅读位置及图集选中项，重新从列表打开从头开始 |
| 请求中断与失败 | 加载中关闭后页面解锁、可以再次打开；获取失败回退到可用独立页 |

专项测试的旧代码复现分别出现两项失败（桌面与手机）：阅读位置回到顶部，图集从第 2 张回到第 1 张。其余当时的路径检查通过。

本次专项浏览器回归为桌面与手机 Chromium；平板使用 768px 视口核对布局。未执行真机 Safari／Firefox 验收，也未逐一人工检查全部文章；共享模板与已选长内容覆盖不能推断所有内容或所有浏览器没有缺陷。测试日志、失败截图、部署回执及私有备份保留在本机 `workflow/.runtime/`，不进入公开仓库。

## 状态恢复取舍

每次打开内容创建独立历史条目 ID，当前文档在内存中保存该条目的滚动位置和图集索引。返回／前进恢复同一条目；重新打开同一 URL 创建新条目，不沿用旧位置。刷新后的旧条目仍按普通页面处理，不跨文档恢复弹窗状态。

`xgif:detail-opened` 保留 `detail.root`，增加可选 `detail.galleryIndex`。图集模块在该事件中恢复选中项和原图链接；弹窗模块等同步初始化完成后恢复外壳滚动位置。无需存储原图副本、正文副本或新增持久化数据。

## 做得好的地方

- 两次新增缺陷都先通过桌面、手机失败用例确认，再修改状态恢复逻辑。
- 保留现有页面跳转、加载失败回退及原图访问，不通过关闭弹窗功能绕开问题。
- 内容和推荐数据不随界面排查重写。
