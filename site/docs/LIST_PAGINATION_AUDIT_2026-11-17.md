# 列表分页专项排查

日期：2026-11-17。范围：列表展示、筛选、历史导航及分页与详情弹窗的交互。本文记录本地候选，未合并或部署。

## 原因与处理

原先只有文章索引支持分页；图片、搜索、标签详情直接输出全部匹配内容，收藏页直接创建全部收藏行。此前测试只检查筛选命中数和弹窗能否打开，没有验证长列表的展示上限及跨页导航。

| 页面 | 本轮处理 |
| --- | --- |
| `/images` | 每页 24 项图片内容，保留类型、情绪与关键词筛选 |
| `/articles` | 保留每页 12 篇；翻页增加历史条目，前进／后退恢复页码与位置 |
| `/search` | 文章和图片各自每页 24 项，避免大量文章把图片结果推到长页面末尾 |
| `/tags/<tag>` | 文章和图片分别分页，每组每页 24 项 |
| `/favorites` | 每页创建最多 24 行；导出、导入、清理仍处理完整收藏；移除末页最后一项时回到有效页 |
| 标签索引和详情的计数 | 图集计为“项图片内容”，不能把内容条目数写成原图张数 |

复用同一分页组件和脚本，避免后续新增列表只接入筛选却遗漏分页。图片相似、推荐来源、原文、展示元数据、内容 ID、排序与原图均未调整。

## URL 与导航规则

- 图片、文章和收藏使用 `page`；搜索和标签分别使用 `articlesPage`、`imagesPage`。
- 筛选基于全部条目，先匹配再分页；改变关键词、类型或情绪后回到第一页，匹配总数与当前范围分别显示。
- 页码仅接受正的安全整数；非法值回第一页，超范围值收敛到末页。只有一页时隐藏分页栏。
- 点击页码建立历史条目；筛选更改替换当前条目。浏览器前进／后退不重新写入 URL。
- 列表历史和弹窗历史分别恢复位置。旧弹窗拥有者标记不足以判断当前条目仍是弹窗的基页，必须同时检查 `detailDialogBase`。
- 滚动过程在文档内存记录位置，在翻页和离开页面时写入历史；避免逐帧调用 `replaceState` 触及浏览器的频率限制。验收位置在瀑布流重排后的稳定帧取样。
- 重建数字按钮后保留键盘焦点；不能让回车翻页把焦点丢回文档。

## 其他列表结论

首页明确为 8 篇文章和 6 项图片的精选，提供全部文章、全部图片及全站搜索入口。详情推荐已有显示上限（图片 3 项、文章通常 3 篇，图片详情的文章推荐 2 篇），不追加分页。“本次浏览”只展示汇总指标。标签索引当前 32 个轻量链接，保留完整索引。

此结论针对当前规模；没有声称全站所有交互或性能问题均已解决。

## 静态架构边界

下述是首轮分页候选的边界。用户随后同意按页获取卡片和延迟加载全文索引，当前候选已由 [ADR-029](decisions/ADR-029-static-catalog-shards.md) 的静态分片方案替代；该候选同样尚未部署。

当前分页属于浏览器渐进增强：列表仍下载完整静态 HTML 与关键词索引，再隐藏非当前页条目。它解决长页面浏览问题，不等同于按页获取数据，也不保证图片请求仅限当前页。原有懒加载与 WebP 展示继续有效。收藏页则仅创建当前页的行。

禁用 JavaScript 时，图片、文章、搜索与标签的静态条目仍全部可访问，分页栏隐藏，计数不宣称仅显示第一页。过滤模块加载失败后，初始化遮挡会自动解除。收藏仍依赖浏览器 JavaScript 和本地存储。

内容规模进一步增大、实测 HTML 传输或 DOM 成本成为瓶颈时，再考虑静态分片和独立搜索索引；不为分页引入在线 CMS 或正文数据库。

## 验证与防漏规范

新增回归覆盖图片准确分片、跨页搜索与清空、无结果、非法／超范围页码、搜索和标签的独立页码、收藏末页移除及完整导出、历史位置恢复、分页弹窗返回、键盘焦点和无 JavaScript 回退；桌面和手机分别运行。

修改分页后，旧图片测试应通过实际搜索控件或准确页码找到固定样本，不能继续假设所有历史图片都在第一页。视觉差异须先确认来自新增范围提示或分页栏，再更新相应 Linux 基线。

另修复测试环境误用：Playwright 不再复用占用相同端口的未知服务。发现本机默认测试端口运行其他项目后，使用隔离端口验证；不关闭其他项目服务。端口可响应不代表正在测试正确站点。

构建／单元测试、浏览器行为和 Linux 视觉结果在本轮交付中分别报告。合并、部署、线上 SHA 核对仍需独立执行；本地测试通过不代表生产已生效。

本轮验证：`npm test` 通过 72 项测试及 513 个 HTML 页面的站内链接检查；Linux 全套 112 项通过，2 项图集专用夹具测试按正常模式跳过，原视觉基线无需更新。最终滚动位置调整后，52 项定向回归中 51 项通过，另 1 项在夹具销毁时出现请求上下文释放错误；增加销毁前等待夹具响应后，Linux 桌面／手机瀑布流 2 项复验均通过。桌面／手机分页栏截图已人工查看。未修改检查阈值或跳过失败用例。
