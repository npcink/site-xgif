# XGIF Visual Baseline

本目录定义当前 Astro 主题的视觉回归基线。旧版 Next 实现位于 `old/next-design-baseline/`，本目录保存关键状态截图和验收规则。

## 图片详情弹层

| 文件 | 含义 |
| --- | --- |
| `next-image-dialog-baseline.png` | 旧版 Next 的目标布局：左图、右侧纸色信息栏、圆形关闭按钮。 |
| `image-dialog-regression.png` | 迁移期间的回归：图片比例撑破网格，文字覆盖图片并出现横向滚动。 |

验收条件：

1. 桌面端图片和信息栏为稳定双栏，图片不得进入右侧文字栏。
2. 图片弹层的比例类不得改变弹层网格列宽。
3. 关闭按钮为右上角圆形 `x`，信息栏使用纸色背景。
4. 小屏幕时，图片与信息栏改为单列；不得出现横向滚动。

## 页面清单

| 页面 | 设计责任 | 当前标准 |
| --- | --- | --- |
| 首页 | 编辑性首屏、摘要与图片的统一浏览 | 保持旧版的两栏 hero、边线网格与纸色/墨色/珊瑚色层级。 |
| 文章卡片 | 扫读、来源与编辑判断 | 信息密度可扫读，标题和摘要不被装饰压缩。 |
| 图片卡片 | 图片优先、情绪标签辅助 | 图片是主角，文字保持在底部遮罩区。 |
| 图片详情 | 快速浏览单个素材 | 以本目录图片基线为准。 |
| 文章详情 | 完整阅读与来源跳转 | 弹层只保留元信息、摘要、标签、来源与完整页入口；独立路由保留完整内容。 |
| 标签与搜索 | 继续发现内容 | 标签用于导航，搜索结果沿用文章卡片与图片卡片。 |
| 移动端 | 单列阅读与可触达操作 | 不允许横向滚动或相互覆盖。 |

## 维护方式

修改主题前，先对照本目录和旧版 Next 档案；修改后至少运行 `npm run build`，并手动检查首页、一个文章详情、一个图片详情和移动端单列状态。
