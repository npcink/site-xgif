# 连续浏览与推荐改进（2026-11-02）

状态：候选实现；本地验证通过，合并与生产核验另行执行。

## 问题与目标

原详情弹窗只提取正文容器，导致容器外的推荐丢失。图片详情只推荐文章，
互相推荐的内容又没有已看过滤，容易在几个页面间循环。首页把图片排在长串文字之后，
完整短文也需要再次打开。此次优先修复这条浏览链，继续使用 Astro 静态产物与 Markdown。

## 页面行为

- 首页混排图片与文字；首项为图片，移除没有真实更新时间支撑的“今日 / 本周”表达。
- 不超过 300 字的普通组文章在卡片内展示完整正文；成人组继续展示摘要。
- 推荐随正文进入弹窗；图片详情先推荐图片，再提供文字入口。
- 文章预留 12 个文章候选，图片详情预留 8 个文章候选，图片候选统一最多 8 个。
  页面每次显示 3 篇文章或 3 张图片；图片详情的文字推荐显示 2 篇。
- 浏览器从候选中跳过本次已看内容，耗尽后提示进入相应内容库，不回收已看内容填满。
- 图片详情提供原图与复制站内链接。跨域原图由浏览器长按 / 右键保存；
  不把打开原图描述成已成功下载。剪贴板失败时提供可选择的只读链接。
- JavaScript 不可用时，初始推荐和普通链接仍可用；去重与计数需要 JavaScript。

## 本机统计边界

按用户选择，当前只做本机验证，入口为页脚“本次浏览”与 `/activity`（noindex）。
使用 `sessionStorage`，不上传 ID、搜索词或计数，不新增线上统计接口。

范围是当前标签页，跨页面延续；不同标签页不持续同步。浏览器从 opener 复制初始会话、
或恢复关闭的会话时可能保留初始记录。通常关闭标签页后清除。

- 已看 ID 最多保存 200 个，仅用于推荐补位。
- 详情成功打开计一次浏览；完整短文末尾连续可见 1.5 秒也计一次展示浏览。
- 推荐至少一半进入可见区域计曝光，每个 DOM 推荐节点只计一次；
  点击发生在观察器回调之前时补记曝光。一个推荐节点只计一次点击。
- 文字末尾连续可见 1.5 秒计“看到末尾”，不能推断读完或满意。
- 后台标签页和被弹窗遮挡的页面不计曝光 / 停留；切换详情时清理观察器与计时器。
- 导出只含数字汇总、范围和时间，不含浏览内容 ID。
- 存储被禁用时保留基本浏览与当页内存去重，无法跨页面汇总，统计页说明限制。

这些数字适合验证推荐链是否工作，不能当作全站点击率、留存或阅读完成率。

## 内容质量与发布拦截

修正 AI 处理回复式摘要、错误标签和明显错分的成人内容。两条不适合公开的既有条目
退回草稿并设置 `publicationHold: true`，未改写原始正文。

构建、内容体检、发布助手的新建 / 编辑 / 批量发布均拦截禁止公开的文章；
普通编辑保存不会丢失或通过 `false` 解除已有 hold，复制草稿也保留该字段。
向量语料加载独立排除 hold，避免误把这类条目发给模型。
hold 只能在专门复核后由维护者直接修改权威元数据，普通发布流程不提供解除动作。
