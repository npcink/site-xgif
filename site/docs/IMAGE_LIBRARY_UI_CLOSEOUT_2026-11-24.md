# 图片库分页与详情样板复盘

日期：2026-11-24。范围：图片库、图片详情及同类控件反馈。本文记录候选决策和本地验证，不作为合并、部署或人工验收回执。

## 讨论与决定

| 问题 | 保留的做法 | 取舍 |
| --- | --- | --- |
| 瀑布流适合分页吗？ | 保留每页 24 项、可直达和恢复的 `?page=`。桌面保留页码捷径；600px 及以下单行显示「上一页、当前页 / 总页数、下一页」。 | 分页限制单次浏览长度，保留可回到的位置。仍先筛选再分页，翻页和弹窗继续恢复历史与焦点；无 JavaScript 使用静态分页链接。 |
| 为什么预览看不出变化？ | 先核实服务目录与当前构建／热更新，再直接打开 `/images?page=3`。首屏、分页所在的页末都要看，按鼠标与触屏分别验证。 | 一个能返回页面的端口不能证明是本轮源码。此前预览未见变化的具体原因没有足够证据，不归因于缓存。 |
| 瀑布流底部能不能完全对齐？ | 保留现有排布。桌面图库的超高图限制展示高度并等比完整显示，不裁原图、不强行拉齐各列底边。 | 完全齐底需要改变排布策略或接受裁切、留白等代价；本轮优先完整图片、稳定顺序和可预测的翻页。 |
| 两个翻页按钮为什么悬停没反馈？ | 增加可用按钮的颜色、描边与指针反馈，以 `(hover: hover)` 判断设备能力，不按窗口宽度关闭悬停。同步排查站头、静态分页、重试、搜索清空、移动菜单和图集控件。 | 当前页、选中项及禁用态各自可辨，键盘焦点独立保留；悬停只增强反馈，不决定操作是否可见。 |
| 为什么站点看着不够精致？ | 先做「图片库 → 图片详情」样板，再决定其他页面怎么复用。 | 问题不只是缺图标或动效：装饰占用首屏，页名、主操作和元信息权重不清，控件状态和边界不一致。先明确任务层级，再统一间距和反馈。 |

## 样板约定

- 借鉴 SoFile 的 `docs/ui-visual-contract.md`：共用对齐边界、操作常显、关键按钮至少 44px 高、短而稳定的反馈。借鉴 blog 的 `tokens.css`、`motion.css` 和 `SectionHeader.astro`：分离页名、说明、元信息和操作，用少量间距与动效变量。只借规则，不引入依赖或复制整套视觉。
- 图库以「图片与表情包」为页名，原标语降为副文案。标题、工具栏与卡片共用左边界；桌面搜索和类型筛选同排，手机分行。计数和加载状态共用一行，描边与图标不抢图片。
- 图片独立页和弹窗共用详情组件，显示原有标题。查看／保存原图为主操作；收藏、复制链接、标签和来源仍可见，保留其各自层级。图集切换不改变画面区尺寸，等待和失败有提示，加载成功短淡入；减少动态效果时不播放淡入。
- 不改变瀑布流算法、目录分片、筛选和分页语义、原始内容与字节、链接、来源或授权。不把样板推广到全站。

## 验证与交接

- 本候选使用的主线基线为 `331405b827dfcbb68446be587ebb6f17cbbf3274`。本地在 1440px、390px 目检图库和详情，首图位置分别由约 562px 提前到 303px、由约 424px 提前到 324px，未见横向溢出。数字仅代表本轮预览视口和样本。
- `site` 的 `npm test` 通过 75 项、站内链接检查覆盖 709 个 HTML 页面。本机 Chromium 定向行为回归 95 项通过、3 项按配置跳过，覆盖分页、键盘、悬停、前进后退和延迟图集。版式断言覆盖 320–1920px。
- Linux 目检并更新图库、筛选图库和详情弹窗共六张基线；用最终源码复跑 `archive-layout|detail-navigation|site.visual`，46 项通过。另一次全量运行在冷构建预览启动阶段超时，不能据此称全量 Linux 已通过；全量结果看候选 PR 的 CI。
- 首轮 GitHub 全量 CI 找到定向复跑漏掉的三个共享断言（桌面、手机共六项）。新版图库不再有装饰页头，窄屏使用紧凑页码，搜索框使用 44px 高度。分别验证图库与其他页面的约定：保留文章及标签的装饰防重叠和其他搜索框的 60px 门槛；覆盖图库标题边界、窄屏分页和恢复数字页码的 601px 断点。没有增加跳过项。
- 保留独立的分页、筛选、详情加载失败与返回测试。后续页面复用时按默认、加载、失败、无结果、有结果和清空逐一核对，不能只对正常态截图。用途不同的页面共享规则，不照搬图库版式。
- 待人工确认：手机上走一遍「筛选 → 点开 → 看原图或切换图集 → 返回」；真机浏览器表现与合并后的线上验收不由本机或 Linux 截图替代。发布仍按 [运行手册](PROJECT_HANDOFF.md#部署与核验) 区分授权、CI、合并、线上 SHA 与巡检。
