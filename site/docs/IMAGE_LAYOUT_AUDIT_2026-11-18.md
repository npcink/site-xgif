# 图片展示细节检查（2026-11-18）

## 已修复

- 图片弹窗的通用 `figure { align-self: start }` 误用于纵向 Flex 图集，令展示区按图片固有比例收窄并靠左。图集展示区现在显式铺满可用宽度；图片继续使用 contain，保留完整画面。
- 手机和平板弹窗的单图高度规则覆盖了图集图片的百分比高度，导致图片与展示区高度不一致。图集图片现在明确跟随展示区高度；单图布局保持原行为。

改动只涉及样式及浏览器回归检查；Markdown、来源、图片字节、图集顺序和原图链接未修改。

## 验证范围

新增几何检查覆盖真实横图、竖图、方图图集的独立页面与弹窗，宽度为 320、390、768、900、901、1024 和 1440px。逐张切换后检查展示区是否铺满、图片是否与展示区对齐、缩略图是否越界、是否产生横向溢出；另覆盖用户反馈的 `20261117-mpyo` 第二张延迟加载图片，并输出桌面和手机截图供查看。

新增检查在修复前于桌面和手机项目均失败，确认能检出原问题。修复后本机站点 75 项测试、579 个 HTML 页面的站内链接检查，以及 56 项相关浏览器检查通过；已查看反馈图片的桌面和手机截图。相关检查同时覆盖单图/动图、长说明、滚动容器、返回/前进、图片/文章切换和瀑布流。

M4 Linux 视觉执行器因宿主可用空间低于 10 GiB 门槛拒绝启动，未清理其他项目或绕过门槛。Linux 视觉基线及完整交互套件交由候选 PR 的 GitHub CI 验证。生产合并、部署和线上验证须另经用户明确授权，本记录不代表已上线。

## 检查结论

在上述范围内未发现其他已确认的同类布局缺陷。既有图集测试只验证显示、切换和高度，无法发现一个靠左收窄但仍可操作的展示区；新增检查直接比较容器与图片的实际几何尺寸，避免只断言 `object-fit: contain`。

## 用户预览后的间距与标签调整

用户进一步反馈 `20261116-rhoh` 信息区间距松散、推荐标题与更多链接堆叠，内容标签不需要胶囊边框。检查确认：信息区各子项独立外边距叠加，来源的自动外边距将其推到桌面栏底，手机断点同时叠加网格间距与内边距，推荐区还有不同的左右内边距。

信息区改为统一 12px 内容间距，来源保留 16px 顶部留白和分隔线；窄屏信息区与推荐区统一左右边界，并移除图片与信息之间重复的网格间距。推荐标题和更多链接在宽度允许时同行，文章推荐标题也允许自然换行以免窄屏溢出。

图片详情、文章卡片和文章正文后的内容标签统一为文本链接/按钮，保留点击、键盘焦点与悬停下划线；图片卡片原有文本标签沿用，筛选与分页控件不受此规则影响。新增回归检查覆盖 320–1440px 的信息区几何尺寸、推荐标题、文本标签和文章共用标签样式。本机站点 75 项及相关浏览器 62 项检查通过，预览中已查看 553px 下的实际弹窗。

## 图片列表页首屏复核（2026-11-18）

用户反馈后补查了 `/images` 首屏。前一轮检查主要围绕图片详情页、弹窗图集和信息区，虽然经过了图片列表的导航与筛选交互，但没有把首屏各区域的实际边界、移动端情绪筛选的可见范围列为独立验收项，因此漏掉了这组版式问题。

本次修正了两处已确认的问题：图片列表首屏标题区和内容区使用了不同的左右内边距，现已统一；移动端情绪筛选原先把 31 个选项压在单行横向滚动，末尾选项在没有明显滚动提示时容易被误认为缺失，现改为两行横向滚动网格，首屏能看到更多选项且保留全部筛选项。

新增浏览器回归检查覆盖 1200、900、600、390 和 320px，验证首屏左右边界、头部工具不越界、筛选网格两行布局、横向滚动范围和页面不产生横向溢出。
