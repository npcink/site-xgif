# XGIF 界面修复复盘（2026-11-23）

本轮以 PR #103 的主线 `dc548b2` 为基线，只改站点交互、样式、部署配置、测试和文档。不改原文、图片字节、公开内容 ID、推荐清单或内容工具。

## 实现与取舍

| 问题 | 处理与验收重点 |
| --- | --- |
| 分开的搜索词无法一起查找；失败后容易误认旧结果 | 多词要求逐个命中，单词仍做连续包含匹配。先保存筛选输入，失败时隐藏不匹配的卡片与计数；普通翻页失败则保留原页和地址。分别验证失败、刷新、重试与返回。 |
| 键盘翻页后焦点丢失 | 成功后把仍在翻页控件上的焦点移入新结果；保留指针翻页与浏览器返回的滚动恢复。 |
| 窄屏图片弹窗的关闭按钮遮图；首屏浏览密度偏低 | 关闭按钮在唯一滚动容器之外。缩短归档页头但不压缩搜索框，标签行保留文章和图片计数。收藏空态同时提供文章、图片和导入备份入口。 |
| 刷新弹窗后快速后退、前进，有时详情地址下仍显示归档 | 延迟加载的脚本可能错过历史事件。初始化时对照实际载入的文档地址与当前历史地址；旧弹窗状态不跨文档恢复。用延迟脚本的测试固定竞态，两种视口均在修复前失败、修复后通过。 |
| 失效链接没有可继续浏览的落点 | 使用静态 404 页面并保留 HTTP 404。实际请求不存在的地址核对状态与三个站内入口，同时覆盖旧弹窗条目指向已移除内容时不会反复刷新。 |

## 验证记录

- `site` 构建及 75 项测试通过；站内链接检查覆盖 580 个 HTML 页面；Wrangler dry-run 和本地 HTTP 404 验证通过。
- Linux Chromium 桌面和移动模拟 220 项通过（含 20 项截图对比）；2 项专用图集用例在独立夹具模式下均通过。只更新了目视复核过的 4 张移动基线。
- 未改动的主线在 12 次移动历史导航对照中复现 3 次失败；最终版本的 3 个相关场景各复跑 12 次，无失败。这不是所有浏览器的兼容性结论。

## 复查：分页失败、慢筛选与键盘重试

- 直达 `/images?page=2` 时，首次加载标记既可能表示筛选，也可能只是请求第二页，不能用它判定错误类型。无筛选的分页直链失败后，显示静态第一页及它自己的页码，保留请求地址以便重试；加载成功才显示第二页卡片和页码。
- 新筛选尚未完成时，旧分页控件不能操作。上一轮请求结束也不能提前解锁仍在运行的新请求。回归用例暂停索引请求，从旧第二页尝试下一页，再验证新结果从第一页开始、分页恢复可用。
- 键盘触发重试后，按钮在请求期间仍保留焦点并拒绝重复激活；成功后仅当焦点仍在重试按钮上，才把它移入已刷新列表。回归用例显式暂停卡片请求，检查重试期间和完成后的焦点，再验证下一次 Tab 的去向。
