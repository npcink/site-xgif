# ADR-027：统一图片库，以动画帧类型筛选

状态：接受（2026-11-16）

图片与 GIF 保持同一个内容库和稳定 URL，增加独立的“全部／静态图／动图”筛选。媒体类型与情绪和搜索条件取交集，保存在 URL 的 `media` 参数中，可分享和刷新恢复。筛选后重新布局瀑布流，数量统计的是内容项而非图集内图片张数。

类型依据 Sharp 读取原始文件元数据中的帧数，不依据扩展名、标题、标签或 AI 结论。动态 WebP 属于动图，只有一帧的 GIF 属于静态图。单图将布尔值保存为 frontmatter 的 `animated`；图集保存在每个有序成员的 `animated` 中。混合图集在静态图和动图筛选中均展示，并标注“含动图”，不拆分原图集。

`image:check` / `image:upload` 返回动画属性供 AI 写入内容。`image:media` 默认预览，`--apply` 从已核验本地原始字节补齐/纠正当前公开图片的属性。无法核验任何原图时停止，不按文件名猜测；写入前检查内容哈希。只改动画属性，不改标题、描述、正文、成员顺序、来源或原图字节。草稿和私有内容不参与批处理。

公开图片缺少属性时构建阻断，提示先核验，不默认为静态图。新增成员后在内容发布前运行补齐，保留原有来源检查、人工合并确认及私有快照流程。这些属性是可重建的文件事实，不纳入 AI 标题或主题推理，也不要求重算原图向量。
