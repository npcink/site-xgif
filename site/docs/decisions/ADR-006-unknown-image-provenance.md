# ADR-006: 允许来源未知图片公开发布并提供投诉下架入口

## Status

Accepted

## Date

2026-07-23

## Context

XGIF 的大部分表情包来自微信群、QQ 群等日常聊天渠道。实际整理时通常无法获得原作者、原始页面或授权链接。继续强制填写 `source`、`sourceUrl`、`author`、`license`、`licenseUrl` 会迫使编辑者放弃发布或填写无法验证的信息。

站点已经有全站可达的 `/rights/` 版权与更正页面和 `1355471563@qq.com` 联系邮箱。需要在不虚构归因信息的前提下，支持这类图片直接发布，并让权利人能够定位投诉和申请下架。

## Decision

- 图片来源类型新增 `unknown`，界面显示为“群聊转存 / 来源未知”。
- `unknown` 图片不要求填写来源、作者和授权字段；Markdown 固定记录 `source: "群聊转存（来源待核实）"`。
- AI 只整理标题、描述、标签、情绪、场景和比例，不推测或生成作者与授权信息。
- `unknown` 图片可以进入公开站点和 R2。
- 图片详情页必须显示“原作者与授权信息待核实”，并直接链接 `/rights/`。
- `/rights/` 公开说明投诉所需材料、处理方式和 `1355471563@qq.com` 联系邮箱。
- 现有 `original` 与 `user_provided` 来源类型和校验规则保持不变。

## Alternatives Considered

### 所有来源未知图片只能保存草稿

风险最低，但与当前以群聊表情包为主的实际内容来源不匹配，会使发布流程基本不可用。

### 将群聊转存统一标记为用户提供

会错误表达“已确认可公开发布”，并污染现有授权台账，因此不采用。

### 由 AI 推测作者和授权

图片内容不能证明权利归属，模型输出也无法构成授权证据，因此不采用。

## Consequences

- 发布流程符合实际数据可得性，不再要求填写无法验证的信息。
- 页面会诚实区分“来源未知”和“已获授权”，历史内容不需要迁移。
- 来源待核实和投诉入口不等于取得授权，公开传播的相关风险仍然存在。
- 收到有效投诉后，需要及时核实、下线、更正或补充归因信息。
