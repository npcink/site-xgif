# ADR-002: 将 Astro 站点收敛到 site 目录

## Status

Accepted

## Date

2026-07-10

## Context

仓库同时包含本地发布台、Astro 站点和旧 Next.js 视觉档案。此前 Astro 文件位于仓库根目录，发布台与站点的所有权边界不清，部署工作目录也容易被误判。

## Decision

- `site/` 独立拥有 Astro 包配置、源代码、内容、静态资源、站点测试和站点文档。
- `workflow/` 保持为根目录下的本地发布台；它在仓库根执行 Git 操作，但只读写 `site/` 的内容与图片路径。
- `old/` 只保存 Next.js 模板和设计基线，不参与站点构建或发布。

## Consequences

- 日常站点命令从 `site/` 运行，部署也以该目录作为工作目录。
- 发布台需要显式维护 `site/` 目标路径；发布台和站点的测试可独立运行。
- 根目录只保留仓库说明、Git 配置和三个顶层子系统。
