# ADR-028：WebP 展示副本与原图分离

状态：接受；日期：2026-11-16

## 原因

卡片、图集主图和 60px 缩略图原先都请求原文件。8 张插画图集首屏传输约 9.25 MiB，缩略图也下载数 MB PNG；原图缓存不能改善首次访问。用户要求默认展示 WebP，主动查看原图时才请求原文件。

## 决定

- 使用现有 Astro 静态图片管线和 Sharp，构建时生成 `/_astro/*.webp`、`srcset` 和小缩略图。原图继续使用原 R2／本地地址，不覆盖或重命名原字节；Markdown、图片身份、推荐源与向量不变。
- 卡片生成 320／640／960px，详情生成 640／960／1280px，均不超过原尺寸；动图卡片为 320／480px，详情为 480／640px，缩略图 120px。浏览器按视口和像素密度选择副本。
- 动画转换保留所有帧、帧间隔及循环次数；薄服务修正 Astro 将 GIF 默认设为无限循环的行为。
- 图集首次只加载封面展示图和小缩略图；切换后才设置其他大图的 `src/srcset`。图片锚点与查看／保存原图按钮始终指向原文件；关闭 JavaScript 时可以通过缩略图直接打开原图。
- 远端转换仅允许 `https://img.xgif.cn/memes/**`；本地公开栅格图片静态导入。SVG、未受管域名或缺少尺寸的数据保持直出，不能宣称任意外链都已转换。
- 新上传内容正常记录原图 URL、尺寸和动画属性，站点构建自动生成副本，不增加上传 API、CMS、图片数据库或收费服务。

## 取舍与限制

Cloudflare 官方提供 `/cdn-cgi/image/...` 转换链接，但当前站点域名实测返回 404，不能当成已可用的功能。静态方案使用现有托管，不消耗在线转换额度。

构建需要下载 R2 原图和编码动图。Astro 缓存可复用；网络失败阻断本次构建，应重试并核对实际部署，不能发布缺失资源。浏览器测试冷构建等待上限为 180 秒，避免原有 60 秒上限把正常编码过程误判为失败。不要在同一 `dist` 中并行构建与性能采样；采样使用构建完成后的固定产物。WebP 并不保证每张都比原 JPEG／WebP 小，收益来自尺寸选择、缩略图与按需加载，不能只比较扩展名。

展示副本不进入图片原始台账、去重身份、语义推荐或 AI 元数据来源指纹。回退组件、服务和配置即可恢复旧显示；原图地址与字节始终保留。

## 配套界面规则

卡片按原比例完整展示，不裁切梗图文字、不用滤镜改变颜色；标签、标题、说明和数量放在图片下面。不同高度的图片使用最短列瀑布流，DOM 与键盘顺序不变。首页第一张图片优先加载，其余延迟加载。

搜索首次筛选后显示结果，脚本失败有超时恢复，禁用 JavaScript 时保留静态索引；可选字体避免迟到的字体替换造成跳动。分页最多 5 个页码；手机页脚按完整链接换行，平板详情折叠侧栏。

## 验证与保留项

构建验证 WebP 格式、120px 缩略图及原图锚点；动画验证帧数、时长和有限循环。浏览器覆盖首次查询 CLS、320px 溢出、分页、焦点、平板正文宽度、图集按需加载、无 JavaScript 回退和 CSP 下瀑布流。Linux 视觉基线查看后更新。

第三方爱站统计脚本仍包含 `new Function` 和 `unload`，存在 CSP 报错及 bfcache 限制。保留用户指定服务与现有 CSP，不使用 `unsafe-eval`、不篡改第三方脚本；需服务商提供兼容版本后闭环，不能报告为已修复。
