# ADR-029：静态列表分片与延迟全文索引

状态：已实现为待审核候选，未部署。日期：2026-11-17。

## 背景

原分页只隐藏静态 HTML 中的其他条目。当前公开内容为 310 篇文章和 160 项图片内容，文章列表及搜索页把全库正文搜索字段嵌入每张卡片，初始 HTML 随全库增长。图片虽然已使用 WebP 和原生懒加载，仍须解析全部卡片。

用户同意改成按页加载，并在开始搜索时获取全文索引。继续使用 Astro 静态构建与 Cloudflare 静态资源，不增加 CMS、在线正文服务、数据库或付费搜索服务。原文、图片、推荐依据及稳定链接不变。

## 决策

1. 普通文章索引初始输出 12 张卡片，图片索引 24 张；搜索和标签详情分别输出各组前 24 张。首页精选及详情推荐保持现有上限。
2. 构建阶段从已公开内容生成 `/catalog/<revision>/`。版本由公开内容快照和格式号生成，不依赖构建机的绝对路径。构建时共用一个快照，开发模式重新读取集合。
3. `articles.json`、`images.json` 是轻量目录：稳定 ID、标题、来源、标签、分片页码及图片类型。翻页／筛选时才请求对应目录。`search-articles.json` 和 `search-images.json` 分别保存公开原文／图片说明等既有关键词字段，只有关键词或需要关键词匹配的情绪筛选才请求。
4. `/catalog/<revision>/cards/<kind>/<page>` 是预渲染卡片 HTML。文章每片 12 张，图片每片 24 张。默认翻页通常只获取下一片；搜索和标签的结果可能分散在多个片中，最多每组并行请求 4 片，只把当前页选中的卡片加入 DOM。
5. 分片里的图片使用 `data-card-src`／`data-card-srcset`，没有活动的 `src`／`srcset`。只激活选中卡片的图片，仍使用 `loading="lazy"`、响应式 WebP 和异步解码。图集的延迟属性独立保留。
6. 请求在当前文档内去重和缓存，失败请求从缓存移除，重试可重新获取。目录和索引有格式号、快照版本和类型校验。静态资源允许重验证缓存，不对仅按内容生成的版本承诺永久不可变的 UI HTML。
7. 网络失败保留已有卡片及 URL，显示错误和重试。重试保留翻页的历史意图；过期查询结果不能覆盖最新输入或详情弹窗 URL。页码、筛选和历史导航沿用既有参数。
8. 关闭 JavaScript 或模块失败时，初始卡片仍可阅读；提供 `/browse/<kind>/<page>` 的普通链接分页，全部公开内容可逐页到达。关键词和组合筛选仍需要 JavaScript。

## 格式与边界

JSON 外层统一为 `{ format: 1, revision, kind, items }`，类型只接受 `articles`／`images`，内容 ID 保持 `YYYYMMDD-xxxx`。分片 HTML 根节点包含 `data-catalog-fragment`、版本及类型，卡片使用 `data-catalog-id`。筛选在浏览器执行，分片路径只指向同源静态资源。

目录和全文索引只投影公开字段，不序列化完整 frontmatter；草稿、私有图片、发布保留文章、私有来源和台账均不进入分片。`/catalog/` 禁止搜索引擎索引，不进入 sitemap；公开内容详情页继续由 sitemap 提供。

只改标题等展示字段时，列表展示分片可以更新；这与推荐向量的来源指纹独立，不能据此重算推荐。

## 取舍

无需浏览全部内容就下载全部卡片 DOM 或全文索引。使用搜索后仍需下载相应种类的完整文本索引，筛选命中分散时会获取多片卡片；这不是在线搜索服务，也不宣称所有请求严格只有一片。

兼容原来的 `?page=2` 等 URL：静态服务器先返回基础页面，浏览器再补取目标页。无 JavaScript 的普通分页使用独立路径，保持可访问性。收藏页继续使用轻量公开标题目录核对本地收藏，实际仅渲染当前页，没有引入正文索引。

构建产物数量增加，但不改变 Cloudflare 运行架构。后续全库全文索引实测成为瓶颈时，再评估进一步文本分片或专用静态搜索；不提前增加常驻服务。

## 验证要求

验证初始 DOM 和请求数量、翻页按需获取、全文独有词命中、缓存复用、失败重试、快速切换、弹窗 URL、历史位置、动态图和原图，以及禁用 JavaScript 的逐页入口。新增 DOM 必须重新加入瀑布流尺寸观察及阅读统计观察，不能只验证数据取回。

运行站点测试及 Linux 桌面／手机交互与视觉回归，比较初始 HTML 及压缩体积；传输估算不替代实际加载时间或 Core Web Vitals。生产发布仍须另行授权。

## 本轮验证记录

站点 73 项测试及 579 个 HTML 页面的链接检查通过，部署 dry-run 通过。Linux 全套首轮 117 项通过，5 项旧用例暴露了预加载假设或等待时机问题；改为通过公开目录定位固定样本并验证普通链接导航后，相关 34 项复验全部通过。最后将错误提示移至筛选区并确保进入视口，加载与性能 18 项 Linux 复验通过。2 项专用图集夹具测试在普通模式中按既有条件跳过，没有放宽视觉阈值或更新基线。
