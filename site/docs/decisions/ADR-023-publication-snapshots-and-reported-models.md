# ADR-023：发布快照核验、响应模型身份和原文搜索

状态：已采纳并实现，2026-11-13；本次随内容同步工具和 CI 核验一起部署。

## 决策

普通内容同步以本地 `origin/main` 的确定提交加本批选中的 Markdown/引用资产创建临时文件系统快照，不将未选的本机内容混入。先尝试复用基线清单；只有本机清单能完整匹配目标快照时才将其加入同步文件与预期 SHA。抓取远端后若基线变动则要求重新规划；隔离分支绑定确定提交，提交前及提交后核验实际提交快照。删除、派生清单单独同步和失败推送重试同样核验目标提交。CI 检查最终合并快照。

清单增加 `publication.schemaVersion=1` 与 `publication.sourceHash`。指纹按稳定顺序覆盖公开 ID、类型、原始正文哈希或有序图片身份、分组及日期。图片为本地实际文件字节哈希，或 `https://img.xgif.cn/memes/<sha256>.<ext>` 中的内容寻址身份。后者依赖存储不可原地覆盖的上传约定；离线核验不代表远端对象可用性或字节的实时下载证明。推荐生成仍核对实际私有备份字节与地址身份。不能离线核验的外部图片阻断发布。AI 展示字段不影响此指纹；发布回执绑定包含清单的确定提交及所选内容哈希。

核验还检查原始输入 `sourceHash`、完整 ID 集合、失效目标、自荐、重复、集合类型和同组约束。共享候选准入只接受同组，不论清单缺失、旧版或部分失效；候选不足允许为空。

元数据生成/审核默认严格匹配请求模型与响应 `model`。只有明确配置的 `REPORTED_MODEL_ALIASES` 可以例外，数组按模型/接口隔离继承，并纳入 provider/run/gate 身份。缺失或不匹配立即停止后续派发，无自动回退/重试。恢复、导出和写回复查存档响应；旧身份策略任务需新建运行。eval-lab 门槛核验响应名称，不能证明服务端实际权重。

文章筛选数据包含公开原始正文，Astro 转义 HTML 属性；内部 frontmatter 不加入搜索。现有同步关键词筛选、URL 状态、分页和计数保留，来源按钮只匹配来源字段。图片说明仍为辅助搜索，不声称已索引原始 OCR。

## 验证及限制

临时 Git 仓库测试覆盖未选内容污染、原始依据变化、AI 字段不变性、基线竞争及异常清单。浏览器复验原文关键词“京东旗舰店金盘”可检索，而展示标题摘要均不含该词。

npcink-eval-lab 增加原始依据推荐的固定 13 案例：11 组正反例及 2 组约束。来源指纹冻结，全文和向量留在私有运行目录，使用现有匹配向量缓存离线导出，不新增模型调用。首轮硬约束通过，质量总评未通过；保留长文尾部主题、探索位位移、非争辩主题召回、讽刺边界及首帧动态图覆盖问题。结果只作小样本编辑诊断，不是独立用户偏好金标准，不自动改变模型或阈值。
