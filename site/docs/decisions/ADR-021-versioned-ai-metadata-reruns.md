# ADR-021：可版本化的 AI 字段重跑

- 状态：已接受，实现与验证保持本地，发布另行执行
- 日期：2026-11-13
- 延续：ADR-019、ADR-020

推荐更新依赖已由 [ADR-022](ADR-022-original-evidence-recommendations.md) 调整：AI 字段重跑/回退不再使向量或清单失效，仅提示核对推荐新鲜度。

## 背景

标题、摘要及图片描述等字段未来需要随模型能力提升重新生成。逐条要求用户审核全部内容不可持续；直接让新模型覆盖 Markdown 又会伤及原文、来源和人工编辑。生成模型选择与推荐向量模型应独立，内容库及试验报告须保留私有。

## 决策

使用按需本地 CLI，将原始资料和 AI 衍生字段分开。字段白名单由文章/图片类型定义，支持按字段选择及本轮保留；正文和来源等资料保持不可变。生成和审核分别配置 OpenAI 兼容或原生 Ollama 模型，不建设后台服务、队列或第二套发布入口。

每轮冻结模型配置、prompt/视觉管线版本、选中字段、来源/当前文件/有序图片哈希和预算。生成只产出候选及依据，审核逐字段评分。每次网络请求先独占记录，成功可断点复用，失败或中断不自动重放，网络与 HTTP 故障停止批次。6 条固定来源由 npcink-eval-lab 独立做离线契约与模型审核分数检查；大于 12 项必须匹配门槛。该门槛没有人工金标准，不取代助手对小样本语义和图片的实查。

组图读取全部成员；动态图描述分析均匀关键帧，保留源图及顺序。写回仅替换白名单 frontmatter 行，先做整批前置检查和私有回执；回退拒绝覆盖后来的字段编辑。所有命令不自动公开草稿、推送或部署。

## 后果与限制

用户可以更换生成/审核模型，先比较相同来源和字段的小样本，再更新全库，不需重新导入正文图片。文章没有独立分类字段，继续沿用现有标签。人工字段通过显式 keep 保留，不猜测历史归属。模型别名与自评不能证明权重固定或质量绝对提高；可提供 revision 时应记录。

多文件写入不宣称原子事务，回执可处理部分完成并回退。共享锁无法拦截外部编辑器，操作必须顺序进行。图集后续变动时回退保守拒绝。推荐管线保持 ADR-020 的模型及首帧策略，AI 元数据更新后另建静态推荐清单；缓存按输入增量复用。

操作、保留字段、评测和回退见 [重跑说明](../../../workflow/docs/AI_METADATA_RERUNS.md)。
