# ADR-025: 用原图主题证据补充图片系列候选

状态：接受（2026-11-13）

图片向量相似度低于阈值，仍可能共享具体的表达主题。例如日用品被赋予夸张名称的梗图，在物体和构图上可以完全不同。不能将零向量命中解释为没有关联，也不能降低阈值后直接自动合并。

保留 Qwen3-VL-Embedding 2B 的成员级纯图片匹配，增加独立、可选的视觉模型比较。比较输入只有核验过 SHA-256 的原图像素；不发送 AI 标题、描述、分类、标签或 alt。模型必须分别给出查询图和候选图的可核对证据，区分同系列、共用模板、主题相关和无关。主题相关只表示有共同表达机制，不声明相同来源、作者或授权。

主题检查不受向量召回阈值限制。每次最多检查 120 张去重后的公开成员，按 6 张分批，最多 20 次模型调用。缺失源文件、预算截断、请求失败、模型身份不符及无效输出均显式报告；启用后检查不完整或出现候选，上传需复核具体文件。GIF/WebP 目前仅比较首帧。

模型、服务地址及 revision 可替换。缓存身份包含模型配置、提示词和输入版本，并以两侧原图 SHA-256 为键；AI 展示元数据变化不触发重算。没有不可变模型 digest 的服务，升级后必须调整 revision 或强制刷新。

所有关联建议仍须用户确认具体目标和成员位置。工具仅报告候选及保存检查记录，不修改正文、图片字节、图集成员或发布状态。上传复核哈希不代表合并授权。
